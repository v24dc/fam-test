# Работа с вебхуком Битрикс24 через bitrix24/b24phpsdk

## Запуск скрипта

1. Добавьте переменную среды с адресом вебхуха Битрикс24. Замените адрес на реальный:

```shell
export BITRIX24_PHP_SDK_INCOMING_WEBHOOK_URL=https://your-bitrix24-portal-url
```

2. Запустите скрипт:

```shell
php src/execute.php
```
